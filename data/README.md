# Data

This project uses the **BPI Challenge 2019** event log, a real purchase-to-pay
dataset from a large multinational company (coatings and paints) published for
process mining research.

- Source: https://data.4tu.nl/articles/dataset/BPI_Challenge_2019/12715853
- Citation: van Dongen, B.F. (2019). BPI Challenge 2019. 4TU.ResearchData.
- License: CC BY 4.0

Download `BPI_Challenge_2019.xes` (~730 MB) and put it in this folder.
The data files are not in the GitHub repo because they are too large.
